### 🛒 Trendyol Test Automation

**Java | Selenium | Cucumber | Karate | JUnit | Maven | GitHub Actions**

A personal e-commerce test automation project focused on guest-user workflows, reusable automation architecture, and CI validation.

#### Project Scope

| Component | Scope |
|---|---|
| Test Scenario Catalog | 48 documented scenarios |
| Selenium / Cucumber | 3 implemented guest-user scenarios |
| Karate | 3 implemented guest-user scenarios |
| Unit Testing | 5 unit tests |
| CI/CD | GitHub Actions |
| Browser Validation | Headless Chrome with local HTML fixture |
| Reporting | HTML / JUnit reports |

#### Technical Highlights

- Structured automated tests using reusable components.
- Applied Page Object Model concepts.
- Implemented Cucumber step definitions.
- Used browser synchronization strategies.
- Configured Maven build validation.
- Added Cucumber dry-run verification.
- Integrated headless Chrome smoke testing.
- Published test reports as CI artifacts.

**CI Transparency:** The CI workflow validates configured unit tests, Cucumber dry runs, and local-fixture browser testing. Planned scenarios and live Trendyol UI tests are not represented as successful CI executions.
